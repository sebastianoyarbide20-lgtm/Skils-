# Skils-

Mis skills para Claude. Cada skill vive en `skills/<nombre>/` con su `SKILL.md`.

## Skills incluidas

Las 9 skills de [heygen-com/hyperframes](https://github.com/heygen-com/hyperframes) (Apache-2.0, ver `LICENSE-hyperframes`):
`hyperframes`, `hyperframes-cli`, `hyperframes-registry`, `remotion-to-hyperframes`, `reverse-any-video`, `slideshow`, `figma`, `media-use`, `style-sampling`.

## Instalar

```bash
git clone https://github.com/sebastianoyarbide20-lgtm/Skils-.git
mkdir -p ~/.claude/skills && cp -r Skils-/skills/* ~/.claude/skills/
```
